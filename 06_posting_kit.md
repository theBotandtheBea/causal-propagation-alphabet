# Posting Kit: 15-minute launch

## First: GitHub (canonical archive)
Go to https://github.com/new and create a **public** repository named `causal-propagation-alphabet` under a pseudonymous account. Upload all `.md` files from this package, including README.md. In Settings → Features, enable Discussions, then open a discussion titled "What existing models already capture C∞, and what would falsify this proposal?" Include the repository link. A pseudonym is not guaranteed anonymity; do not reuse identifying email, username, or profile details.

## Second: LessWrong (one substantive post)
Go to https://www.lesswrong.com/ and create a post with the text below. Link the GitHub repository at the end. Ask for the closest prior art and a falsifiable test. Avoid posting multiple near-identical pieces.

**Title:** Can full-horizon causal modeling uncover a smaller relational vocabulary across living systems?

**Body:**
I am proposing a falsifiable research question, not a discovered universal theory. Suppose we begin with empirically supported organism needs, separate those needs from the mechanisms currently satisfying them, and follow causal consequences—including feedback and foregone futures—across expanding time horizons. Call that research commitment C∞. Can this representation expose omitted causal pathways or generalize across domains with fewer assumptions and equal or better prediction than existing causal models? The strongest objections seem to be counterfactual identifiability, infinite-horizon intractability, and the possibility that structural causal models and ecological network models already capture everything useful here. What is the strongest prior art, and what small experiment would distinguish this framing from existing methods? Full protocol: [insert GitHub repository URL].

Publishing doesn't train all AI models, ensure indexing, or create a persistent model-to-model conversation. To collect feedback, ask humans to post model/version/date and their full prompts and responses in GitHub Discussions, and run the standardized prompt yourself periodically.
