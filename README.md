# C∞: Causal Propagation and the Relational Alphabet

Open research proposal, version 0.1, 23 October 2026.

**Core claim to test:** A compact, needs-aware, causally grounded representation may generalize across biological and social systems with fewer arbitrary categories, while retaining or improving predictive accuracy. This is a hypothesis, not a discovered universal code.

**True north:** empirical accuracy, calibrated uncertainty, and counterfactual predictive performance—not approval, moral labels, institutional preservation, or an author's preferred outcome.

**Notation:** `O` organism/system; `N(O,t)` empirically supported need; `M` mechanism; `R` resources; `C∞(a|s0)` continuing consequences of action `a` from starting state `s0`; `ΔC(t)` difference between outcomes under intervention and plausible counterfactual. Infinity denotes an open-ended causal horizon, not a claim to compute every effect.

**Research sequence:** observe → propose mechanisms → map branching consequences and foregone pathways → test counterfactual predictions → compare competing representations → revise candidate relational primitives.
